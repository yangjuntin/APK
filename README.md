# 耗电测试工具（PowerDrainTest）

一个用于**安卓平板续航 / 耗电测试**的本地 APK。一键开启多种耗电负载快速消耗电量，并在电量降到你设定的阈值时**自动停止**。

> 适用：未 root 的安卓平板 / 手机（minSdk 21，Android 5.0 及以上）。

---

## 一、功能

- **一键开始耗电**，可自由组合以下负载：
  - CPU 满载计算（线程数可调，默认 = 核心数）
  - 屏幕最高亮度 + 常亮
  - 开启闪光灯（无闪光灯设备自动禁用该项）
  - 持续震动马达
- **实时显示**：电量百分比、电池温度、电压、充放电状态、本次已掉电量、耗时。
- **自动停止阈值**：用滑块设定（0–100%），电量降到该值自动停止并提示。
- 测试期间通过 WakeLock + 屏幕常亮保持负载持续运行。

## 二、你不需要装任何环境 —— 用 GitHub 云端自动编译出 APK

因为本机没有 Android 开发环境，最省事的方式是让 **GitHub Actions** 在云端帮你编译，全程网页操作，几分钟生成 APK。

### 步骤

1. **注册 / 登录 GitHub**：https://github.com

2. **新建一个仓库**（New repository）：
   - 名字随意，例如 `PowerDrainTest`
   - 选 **Public**（私有仓库的 Actions 也可用，免费额度足够）
   - 不要勾选任何初始化文件，直接 Create

3. **上传本工程的所有文件**：
   - 在仓库页面点 **Add file → Upload files**
   - 把 `PowerDrainTest` 文件夹**里面**的全部内容（包含 `.github` 文件夹、`app` 文件夹、`build.gradle` 等）拖进去上传
   - 重要：`.github` 文件夹必须一起上传，否则不会触发自动编译
   - 填写提交说明，点 **Commit changes**

4. **等待云端编译**：
   - 进入仓库顶部的 **Actions** 标签
   - 会看到一个名为 **Build APK** 的运行任务（黄色=进行中，绿色=成功）
   - 大约 3–5 分钟完成

5. **下载 APK**：
   - 点进绿色✅的那次运行
   - 滚到页面底部 **Artifacts** 区域
   - 下载 `PowerDrainTest-debug-apk`（是个 zip，解压后得到 `app-debug.apk`）

> 如果没有自动触发：进 Actions → 左侧选 **Build APK** → 右侧 **Run workflow** 手动运行一次。

---

## 三、安装到平板

1. 把 `app-debug.apk` 传到平板（数据线 / 网盘 / 微信文件传输等）。
2. 平板设置里允许「安装未知来源应用」。
3. 点击 APK 安装并打开。

---

## 四、使用

1. 打开 App，顶部实时显示当前电量与温度。
2. 用滑块设置「自动停止电量阈值」（例如 30%）。
3. 勾选想要的耗电负载，调好 CPU 线程数。
4. 点 **一键开始耗电**。
5. 想中途停止点 **停止**；电量降到阈值会**自动停止**。

**测试建议**
- 测试时**不要充电**，保持 App 在前台。
- 关注电池温度，**过热（如 >45°C）请立即停止**，避免设备损坏。
- 闪光灯长时间点亮会发热，注意散热。

## 六、常见问题

- **Actions 编译失败？** 点进失败的运行查看红色步骤日志，通常是文件没上传全（尤其 `.github/workflows/build.yml`、`gradle.properties`、`settings.gradle`）。确认目录结构与本工程一致后重新上传。
- **装不上？** 确认已允许「未知来源」安装；若提示已存在，先卸载旧版本。
- **闪光灯选项是灰的？** 该设备无闪光灯，属正常，其它负载照常使用。
